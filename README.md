## Production Implementations & Impact

### 1. NVRON Refill Control Operating System (RCOS)
*Doctor Acquisition, Logistics Management & Predictive Healthcare CRM*

* **System Design:** Engineered an automated B2B pipeline designed to systematically transition reactive ordering models into predictable, data-driven fulfillment streams.
* **Lead Qualification Pipeline:** Built a multi-variant evaluation matrix that tracks, profiles, and processes customer targets across strict operational phases ($\text{New} \rightarrow \text{Validated} \rightarrow \text{Nurturing} \rightarrow \text{Qualified} \rightarrow \text{Scheduled} \rightarrow \text{Closed}$) based on OPD potential, regional location data, and pharmacy asset properties.
* **Predictive Replenishment Engine:** Developed an analytical tracking module evaluating historical clinical consumption patterns to determine depletion schedules and dynamically execute targeted CRM alert workflows.
* **Hierarchical Affiliate Networks:** Formulated multi-tier data structures isolating commission slabs, performance-tier pay scales, and distinct markup variables for Regional (RAP) and Municipal (MAP) partner channels.
* **Architecture:** React 18 / Vite / TanStack Query frontend layer interface tied to a Node.js / Express.js API backend driving a Supabase PostgreSQL instance utilizing strict Row Level Security.

### 2. NVRON Manufacturing ERP System (NVRON-OS)
*Compliance, Quality Control & Material Traceability Architecture for Regulated Manufacturing*

* **System Design:** Purpose-built system engineered to secure real-time regulatory compliance (Pharma / FSSAI), execute end-to-end material tracking, and stabilize gross margins through volatile supply cycles.
* **Audit & Sanitation Tracking:** Designed tamper-resistant logging modules capturing continuous operational checklists, equipment cleanliness records, and critical RO water processing metrics (pH, TDS, conductivity, and flow pressure parameters).
* **Batch Traceability Schema:** Modeled strict schema relationships binding uniquely generated batch identifiers directly back to raw material Goods Received Notes (GRNs) and manufacturer Certificates of Analysis (COA) to secure comprehensive recall proofing.
* **Procurement Price Controls:** Developed an RFQ bidding framework with systematic price freezes to insulate raw material procurement operations against market-driven price inflation.
* **Architecture:** Node.js, Express.js, and an enterprise PostgreSQL database layer implementing strict Role-Based Access Controls (RBAC) to guarantee site-isolated data containment across multi-warehouse locations.
